    Welcome to Curator

    Local gallery browser powered by gallery-dl.

    Everything Curator downloads — your media, its database, and its settings — stays on this machine. Nothing is uploaded anywhere. This short setup checks that Curator has what it needs, then gets out of your way.

    ffmpeg/ffprobe is only used to split videos into a "clips" vs "videos" view by duration. Everything else works without it.

    Data directory

    Curator stores downloaded media, its database, settings, and logs here.

    Curator never moves existing files when you change this — pick a directory that either doesn't exist yet (it'll be created) or already holds a Curator library you want to keep using.

    gallery-dl configuration

    …
    gallery-dl

    gallery-dl keeps its own configuration file (for things like site logins and cookies) separately from Curator — this wizard doesn't ask for passwords or cookies. See gallery-dl's own documentation for site-specific login setup; Curator will use whatever gallery-dl is already configured to do.

    Download defaults

    New sources start downloading as soon as they're added, and gallery-dl's own per-source archive already skips files it's downloaded before — both happen automatically, no extra setup needed here.

    Content classification

    Optional: a local classifier can automatically set a 1–5★ rating on new (and, in the background, existing) images — 1★ clothed/safe up to 5★ extremely explicit — for anything you haven't already rated by hand.

    P-HAR is separate from NudeNet. On Windows it uses a managed native CUDA or supported ROCm environment; no model download occurs in the installer. You can also manage it later from Local Admin.

    Turning this on when the environment isn't ready yet is fine — Curator will just leave items unrated until the classifier's dependencies are installed. See curator --docs for setup instructions.
