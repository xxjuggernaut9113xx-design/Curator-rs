    Media

    Videos at or below this duration are Clips. Changing it only reclassifies views; it never edits source files.

    Restart required: FFmpeg changes take effect when Curator next starts.

    Download-size limits

    Known oversized remote items stay as placeholders with a skip reason. They are not archived as downloaded and re-sync after increasing or removing the limit can fetch them.

    A running remote source can exceed its quota by up to one permitted file before it pauses.

    Disk reserve and thumbnail cache

    A thumbnail-cache limit uses least-recently-used eviction. It never changes originals.

    Storage usage and cleanup

    Open this tab to calculate storage usage.

    Automatic cleanup only follows an enabled source retention rule and protects favorites, human-rated media, group members, and source covers. It never recompresses originals. Deleting archives can make gallery-dl reconsider older posts later.
